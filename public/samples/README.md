# Sample clips

Drop audio files here and list them in `manifest.json`. While the manifest is an empty array, the sample picker is hidden.

```json
[
  {
    "title": "Studio voice, real",
    "file": "real-01.wav",
    "label": "real",
    "source": "Where the clip came from, with a link",
    "licence": "The licence that allows public redistribution"
  }
]
```

Only add clips you recorded yourself or whose licence you have confirmed. Keep each under 15 seconds.
